# Security policy

Codo runs commands and edits files on your computer, so security reports matter a lot to us.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/DomaAI/codo/security/advisories/new)
or by email to bezpieczenstwo@madd.im.

Include the Codo version (`codo version`), your operating system and the steps to reproduce.
We reply within 3 working days and tell you when a fix is released.

## Scope

In scope: the `codo` file, the installers in this repository, and how Codo stores keys and
handles consent for edits and commands.

Out of scope: Claude Code, Codex, Gemini CLI and model providers themselves. Report those to
their owners.

## Supported versions

Only the latest release gets security fixes. Update with `codo update`.
